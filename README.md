# DS&A — Shortest Paths in Weighted Graphs

## About the course

This repository is part of my coursework for **Data Structures and Algorithms**, a university course on algorithm analysis and design. Topics include asymptotic analysis, sorting, balanced search trees, hashing, graphs and shortest-path algorithms, dynamic programming, and amortized analysis — with both written theoretical exercises and a final programming project.

## About this assignment

The theme of this exercise is shortest paths in directed, non-negatively weighted graphs. A central question asks to extract, from a graph `G` and source `s`, the set `E'` of edges `(u, v)` that lie on at least one shortest path from `s` to `v`, with a target runtime of `O(n log n + m)`. Answers provide pseudocode, a correctness proof, and a runtime analysis — typically by augmenting Dijkstra's algorithm and post-processing the shortest-path DAG.
